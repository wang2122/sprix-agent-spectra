# Contributing

Thank you for improving SPECTRA. Contributions should preserve scientific traceability and avoid overstating results.

1. Open an issue describing the measurement or engineering problem.
2. Create a focused branch and include tests for behavioral changes.
3. Run `ruff check .` and `pytest`.
4. For new metrics, document estimand, assumptions, failure modes, and aggregation.
5. For benchmark claims, include seeds, task versions, environment/tool permissions, confidence intervals, and raw artifacts.
6. Submit a pull request. The commit history, reviews, and Contributors graph attribute the work.

Do not add proprietary prompts, personal data, leaked benchmark items, or credentials. Synthetic and real-world results must be clearly distinguished.
